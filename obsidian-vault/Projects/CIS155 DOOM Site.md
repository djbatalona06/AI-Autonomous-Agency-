# CIS155 DOOM Site

**Repo:** `djbatalona06/create-your-own-website-cis155`
**What it is:** Coursework for CIS155 ("Create Your Own Website") — a static 4-page HTML/CSS
site, no JS framework. Topic: **"Can It Run DOOM?"** — a fan page about DOOM (1993) and the meme
of it running on unlikely hardware (calculators, pregnancy tests, tractors, ATMs).

Graded incrementally by module/week (commit history shows "module 3/4 DOOM upgrade for my
assignment"). Still in progress: nav links to "The Story," "Devices That Run DOOM," and "Gallery"
are placeholders.

**Note:** the repo also still contains unfinished leftover template content about a "My PNW
Garden" site (blog post byline "Lindsey Handley"), inherited from an instructor/classmate
template repo (`ldhandley/my-website`) via a `git` file transfer. **That gardening content is not
DJ's own and should not be attributed to him** — it's just not fully replaced yet.

Signals: interest in retro gaming / internet meme culture; this is a class exercise, not a
polished personal portfolio — no resume or contact info lives here.
